# Безопасность

Ключ подписи, пароли и пользовательские резервные копии в репозиторий не включены. Не добавляйте их в историю Git и не используйте настоящий банковский PIN в калькуляторе.

## Импорт JSON

В APK 1.3 и соответствующих автономных исходниках идентификаторы профилей при импорте вставляются в HTML без достаточного экранирования. Специально подготовленный сторонний JSON способен внедрить обработчик событий в страницу.

До исправления в новой сборке импортируйте в APK 1.3 и автономную версию только собственные, доверенные файлы. Не открывайте резервные копии неизвестного происхождения.

В `web/index.html` это место исправлено экранированием идентификаторов. Исправление веб-версии не изменяет уже собранный APK.

## Локальные данные

Резервная копия JSON содержит введённые имена, даты и другие параметры в открытом виде. Храните её как личный документ и не прикладывайте к публичным Issues.
