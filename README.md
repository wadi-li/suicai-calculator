# Калькулятор Сюцай

Веб-калькулятор, автономный HTML и Android-приложение для нумерологических расчётов по дате рождения. Проект предназначен для развлечения и знакомства с методикой, а не для принятия медицинских, финансовых или иных ответственных решений.

- [Открыть опубликованный калькулятор](https://suicai-calc.pplx.app).
- [Android APK 1.3](web/Suicai-1.3.apk): откройте файл и выберите **Download raw file**.
- [Автономный HTML](offline/suicai-calculator.html): скачайте файл и откройте в браузере.

## Возможности

- Матрица, число сознания, предназначения и характера.
- Сравнение пары и группы, сохранённые профили.
- Подбор номера телефона и символического финансового кода.
- Календарь дней для дел, отдыха и путешествий.
- Определение исторического смещения UTC по городу и дате через встроенную базу часовых поясов браузера.
- Города по алфавиту, включая Харьков, Владивосток, Екатеринбург, Омск, Новосибирск и Санкт-Петербург.
- Импорт и экспорт JSON, экспорт CSV и календаря ICS.
- Светлая и тёмная темы, адаптивный интерфейс.

## Хранение данных

В автономном HTML и Android-приложении данные хранятся локально. Очистка данных приложения, удаление приложения или очистка хранилища браузера может их удалить, поэтому рекомендуется экспортировать резервную копию JSON.

В `web/index.html`, соответствующем опубликованному сайту, используется хранилище в памяти страницы. После перезагрузки данные не сохраняются; для переноса используйте «Сохранить копию данных» и «Загрузить копию». Серверной базы и синхронизации между устройствами нет.

## Установка Android

Скачайте `web/Suicai-1.3.apk` на телефон и откройте его. При необходимости разрешите установку приложений из выбранного браузера или файлового менеджера.

- Минимальная версия: Android 7.0, API 24.
- Версия приложения: 1.3, versionCode 3.
- Пакет: `ru.suicai.calc`.
- APK не запрашивает разрешение доступа к интернету.
- Это самостоятельная сборка, а не приложение из Google Play.

```text

```

## Сборка Android

Нужны Linux, JDK 17, Android SDK Platform 34, Build Tools 34.0.0 и утилита `zip`. В репозитории нет Android SDK, JDK или ключа подписи.

```bash
export JAVA_HOME=/путь/к/jdk-17
export ANDROID_SDK_ROOT=/путь/к/android-sdk
bash android/build.sh
```

Без параметров подписи будет создан `android/suicai-unsigned.apk`. Его необходимо подписать перед установкой.

Для подписи собственным ключом:

```bash
export SUICAI_KEYSTORE=/путь/вне/репозитория/release.jks
export SUICAI_KEY_ALIAS=release
read -rsp "Пароль хранилища: " SUICAI_STORE_PASSWORD; echo
export SUICAI_STORE_PASSWORD
read -rsp "Пароль ключа: " SUICAI_KEY_PASSWORD; echo
export SUICAI_KEY_PASSWORD
bash android/build.sh
unset SUICAI_STORE_PASSWORD SUICAI_KEY_PASSWORD
```

Результат: `android/suicai.apk`. Сборка с новым ключом не сможет обновить установленный APK 1.3 поверх него: для обновлений нужен тот же исходный ключ; перед переустановкой с другим ключом экспортируйте данные.

Готовый APK 1.3 сохранён без изменений. Java- и HTML-исходники в `android/` соответствуют этой сборке; веб-версия дополнительно содержит кнопку скачивания и исправление экранирования идентификаторов импортируемых профилей. См. [ограничения безопасности](SECURITY.md).

## Проверки и ограничения

APK проверен на структуру и подпись, веб-интерфейс и загрузка файлов проверены в Chromium. Проверка на физическом Android-устройстве или эмуляторе не выполнялась.

Исторические часовые пояса зависят от версии базы данных в браузере/WebView. Для введённых вручную координат используется ближайший город из ограниченного списка, а не полноценное определение границ часовых поясов; результат нужно сверять.

Нумерологические оценки не являются научно подтверждённым прогнозом. Предлагаемый финансовый код не следует использовать как настоящий банковский PIN или пароль; рекомендации по путешествиям не заменяют проверку погоды, маршрута и безопасности.
